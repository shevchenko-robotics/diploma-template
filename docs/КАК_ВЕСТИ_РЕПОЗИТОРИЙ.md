# Как вести репозиторий выпускной работы

## Начало

1. На странице шаблона [vkr-robotics/diploma-template](https://github.com/vkr-robotics/diploma-template) нажмите **Use this template → Create a new repository**. Owner — `vkr-robotics`, видимость — **Private**.
2. Назовите репозиторий по теме работы латиницей через дефис, например `mobile-robot-navigation`.
3. Заполните README: тема, автор, цель и задачи. Текст в угловых скобках заменяйте вместе со скобками. Удалите строку «Шаблон…».

Уже есть свой репозиторий? Перенесите его в организацию (Settings → Danger Zone → Transfer ownership → `vkr-robotics`), переименуйте по теме работы и скопируйте из шаблона файлы `.gitignore` и `.gitattributes` — без них в репозиторий попадут временные файлы, а тяжёлые модели не уйдут в LFS.

## Почта в коммитах

Адрес из `git config` виден в истории каждого коммита. Чтобы не показывать личную почту, один раз настройте служебный адрес GitHub:

1. GitHub → Settings → Emails: включите **Keep my email addresses private** и **Block command line pushes that expose my email**. Ниже появится адрес вида `12345678+login@users.noreply.github.com`.
2. Укажите его в git:

```sh
git config --global user.name "Имя Фамилия"
git config --global user.email "12345678+login@users.noreply.github.com"
```

## Правила

- **Коммитьте регулярно** — хотя бы раз в неделю, пока идёт работа. История коммитов показывает ход работы лучше любого отчёта.
- **Пишите понятные сообщения коммитов:** «Добавил расчёт привода», а не «update» или «.».
- **Храните исходники, а не только результаты:** модели CAD вместе с экспортом в STEP и PDF, код вместе с инструкцией по запуску.
- **Не храните мусор:** временные файлы, сборки и резервные копии уже исключены в `.gitignore`.
- **Отмечайте этапы метками** (tag): `predzashchita`, `zashchita`. Так легко вернуться к версии, которую вы показывали.

## Большие файлы

Тяжёлые модели, видео и архивы лучше хранить через [Git LFS](https://git-lfs.com) — расширения уже прописаны в `.gitattributes`. Установите LFS один раз командой `git lfs install`. Без LFS файлы тоже сохранятся, но репозиторий будет быстро расти.

Файлы больше 100 МБ GitHub не примет: такие видео выкладывайте на внешний ресурс и оставляйте ссылку в README.

## Приватность

Приватный репозиторий в организации `vkr-robotics` видите вы и руководитель — добавлять кого-то вручную не нужно. Сделать его публичным (например, для портфолио) можно в любой момент: Settings → Danger Zone → Change visibility. Если в работе есть закрытые данные предприятия, оставьте репозиторий приватным.
